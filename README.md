# The Legacy of the Omniverse

Web app personale con l'ordine di visione dei 36 episodi principali della saga **The Legacy of the Omniverse** di UnrealEntGaming.

La pagina viene generata automaticamente con `yt-dlp`, così i pulsanti puntano ai video pubblici corretti senza dover copiare i link a mano.

## Applicazioni online

- [**The Legacy of the Omniverse**](https://xhazer39.github.io/gheto/) — ordine di visione della saga.
- [**Meal Builder / Meal Prep**](https://xhazer39.github.io/gheto/meal/) — pianificazione di pasti e giornate alimentari.
- [**Kurose Grind – Reti**](https://xhazer39.github.io/gheto/reti/) — applicazione di studio per il corso di reti.

## Pubblicazione

GitHub Actions genera la cartella `public/` e la pubblica con GitHub Pages a ogni modifica del repository.

Su iPhone o iPad: aprire il sito in Safari, toccare **Condividi** e scegliere **Aggiungi alla schermata Home**.
